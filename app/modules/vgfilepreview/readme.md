## VGFilePreview

Модуль предпросмотра файлов для карточек/строк с атрибутом `data-vg-filepreview`.

### Что умеет

- Определяет тип файла по пути/расширению и подставляет соответствующую SVG-иконку.
- Заполняет поля карточки:
  - имя файла;
  - расширение;
  - оригинальное имя (для медиа, если передано);
  - размер (если доступен).
- Отображает кнопку скачивания, если в `data-fields` есть поле `download`.
- Открывает предпросмотр в зависимости от формата:
  - изображения: модалка (`VGModal`);
  - аудио: нижний сайдбар (`VGSidebar`) с плеером;
  - видео: модалка с автозапуском;
  - текстовые файлы: модалка с содержимым;
  - `md`: рендер markdown;
  - архивы (`zip`): просмотр содержимого + предпросмотр поддерживаемых внутренних файлов;
  - `pdf`: отдельный просмотрщик в модалке;
  - office-документы (`doc/docx/xls/xlsx/ppt/pptx/...`): модалка через web-viewer.
- Для аудио/видео поддерживает переход между соседними медиа файлами (playlist prev/next).

### Состояния и валидация

- Проверяет путь до файла (`_validateFilePath` в helper).
- Синхронизирует валидность через атрибуты:
  - `data-vg-filepreview-valid`;
  - `data-vg-filepreview-error`.
- Ставить состояние рендера в `data-vg-filepreview-state`:
  - `loading`;
  - `ready`;
  - `empty`;
  - `error`.

### Атрибуты и поля

- `data-vg-filepreview` — путь к файлу (обязательный).
- `data-fields` — список полей, которые нужно заполнить (через запятую).
- Поддерживаемые имена полей:
  - `icon`, `name`, `ext`, `size`, `original_name`, `preview`, `download`.

Поле привязывается по CSS-классу внутри элемента модуля (например, `.name`, `.icon`, `.download`).

### Локализация

Модуль использует i18n-ключи `filepreview.*` из `app/langs/*/{buttons,messages}.json`.

### Расширение

Рендереры подключаются через `js/renderers/index.js`.  
Чтобы добавить новый тип предпросмотра:

1. Создать рендерер в `js/renderers/`.
2. Реализовать `canRender(context)` и `render(context)`.
3. Подключить его в `js/renderers/index.js` в нужном порядке приоритета.
